# 0001 Foundation Spec

## Objective
Bootstrap BitBetMatic 2.0 with a production-minded repository foundation that supports safe, spec-driven MVP delivery.

## In scope
- modular solution/project scaffolding
- placeholder contracts and host bootstraps
- baseline docs and decision records
- agent scaffolding (roles, rules, skills, workflows)
- CI and local dev infrastructure setup
- starter test coverage for invariants and boundaries

## Out of scope
- real trading strategy logic
- live exchange execution
- complex ranking/business logic
- production deployment scripts

## Acceptance criteria
- repo structure matches foundation architecture
- API/Worker/Dashboard run as placeholders
- tests exist and validate non-trivial assumptions
- docs make implemented vs deferred scope explicit
- CI validates build/test/build-dashboard flow
