# Decisions — Epic 0005

## D-0005-1
The first release optimizes for controllability, observability, and audit trail clarity over market realism.

## D-0005-2
Every signal-driven action must emit a persisted, correlated audit event.

## D-0005-3
Paper execution behavior is intentionally minimal and deterministic for MVP.

## D-0005-4
Advanced order types and exchange-specific execution mechanics are explicitly deferred.

## D-0005-5
Operator visibility is a core requirement of this epic, not optional polish.
