# Link AI Overlay Guidance in Primary Docs

## ID
T-0402

## Type
Task

## Parent
S-0401

## Summary
Cross-link the AI overlay guidance from `README.md` and workflow docs.

## Problem / Context
Guidance is ineffective if maintainers and AI agents do not encounter it in primary documentation entry points.

## Goals
- Make overlay-sync guidance discoverable from core project docs.

## Non-goals
- Rewriting all contributor documentation.

## Requirements
- [ ] R1: Add a reference to the AI overlay guidance in `README.md`.
- [ ] R2: Add a reference to the AI overlay guidance in workflow-oriented documentation.

## Acceptance Criteria
- [ ] AC1: README contains an explicit link to overlay-sync guidance.
- [ ] AC2: At least one workflow doc contains an explicit link to overlay-sync guidance.

## Dependencies
- S-0401
- T-0401

## Open Questions
- Which workflow document should be considered the canonical entry point for AI-agent execution?

## Notes
Links should describe when and why guidance must be followed.
