# Surface Structural Warnings for Triage

## ID
S-0301

## Type
Story

## Parent
F-0011

## Summary
As a user, I need clear validation warnings so I can fix spec or overlay issues before relying on planning outputs.

## Problem / Context
Silent structural issues undermine trust in recommendations.

## Goals
- Make warnings visible and filterable.

## Non-goals
- Automated corrections.

## Requirements
- [ ] R1: Display rule ID, severity, message, and source reference.
- [ ] R2: Allow filtering by severity.

## Acceptance Criteria
- [ ] AC1: Errors and warnings are distinguishable at a glance.
- [ ] AC2: Selecting warning focuses related item when available.

## Dependencies
- F-0010
- F-0011

## Open Questions
- None.

## Notes
Warning visibility is key to operational trust.
