# Adapters (Placeholder)

Adapters translate different source ecosystems into the canonical SpecForge model.

## v1.0 expectation

- one baseline markdown adapter for local repositories following `/specs` conventions

## Post-v1.0 possibilities

- adapters for alternate spec structures
- remote source adapters
- adapter-specific drift compensation utilities

Adapters should output canonical entities and parser diagnostics, not UI-oriented structures.
